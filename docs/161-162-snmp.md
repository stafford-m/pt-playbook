# 161/162 - SNMP

## Service Scanning

Confirm with banner grab
```bash
nc -u -v -w4 $ip 161
```

Scanning with nmap Scripts
```bash
nmap -p 161,162 -sU -sV -sC $ip
```

## Service Enumeration

Community strings

output like: 192.168.0.25 [public] Hardware: Intel64 Family 6 Model 79 Stepping 1 AT/AT COMPATIBLE - Software: Windows Version 6.3 (Build 17763 Multiprocessor Free)
```bash
onesixtyone -c /usr/share/wordlists/seclists/Discovery/SNMP/common-snmp-community-strings-onesixtyone.txt -i ips_specific.txt
```

public strings (v2, v2c, and v3 also exist)

output like: iso.3.6.1.2.1.55.1.5.1.2.22 = STRING: "Red Hat VirtIO Ethernet Adapter"
```bash
snmpwalk -c public -v1 -t 10 $ip
```

Includes snmp-brute and other auto-enumeration
```bash
nmap 192.168.70.151 -p 161,162 -sU --script snmp-*
```

## Config Paths

snmpd (Linux)
```text
/etc/snmp/snmpd.conf
```
Windows SNMP service
```text
HKLM\SYSTEM\CurrentControlSet\Services\SNMP\Parameters
```

Config quick-reference:
```text
snmpd.conf -> rocommunity public, rwcommunity private, access control
```

## Post-Enumeration

- Dumped users → spray across SMB/SSH/WinRM/HTTP
- Dumped processes/software → identify vuln software for exploit selection
- rwcommunity (write) → can set values (sometimes used to write routes/config)

### Common gotchas
```text
- UDP-based → use -sU on nmap, and note UDP scans are slow.
- Only v2c/v1 typically. v3 needs auth/priv creds (rare on OSCP).
- Public (read-only) is enough to win — write community (private) is a bonus, not required.
- onesixtyone is much faster than snmpwalk for brute — use it first.
- onesixtyone -c <file> $ip works, but for many hosts use -i targets.txt.
```
