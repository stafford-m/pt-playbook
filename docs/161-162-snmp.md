# 161/162 - SNMP

## Service Usage

Walk the full tree (v2c, public community)
```bash
snmpwalk -v 2c -c public $ip
```
Walk the full tree (v1, public community)
```bash
snmpwalk -v 1 -c public $ip
```
Walk a targeted OID for users
```bash
snmpwalk -v 2c -c public $ip 1.3.6.1.4.1.77.1.4.1
```
Walk a targeted OID for processes
```bash
snmpwalk -v 2c -c public $ip 1.3.6.1.2.1.25.4.2.1.2
```

## 0. Fast Path (try these first)

Test default community strings immediately
```bash
for c in public private community; do
  snmpwalk -v 2c -c $c $ip 1.3.6.1.2.1.1.1.0 && echo "[+] $c works"
done
```
Full walk with the working community string
```bash
snmpwalk -v 2c -c public $ip > snmp_loot.txt
```

## 1. Banner Grab & Unauthenticated Enumeration

UDP version and default-script scan
```bash
nmap -p 161,162 -sU -sV -sC $ip
```
SNMP brute and info NSE scripts
```bash
nmap -p 161 -sU --script snmp-brute,snmp-info $ip
```
Brute community strings with onesixtyone
```bash
onesixtyone -c /usr/share/wordlists/SecLists/Discovery/SNMP/common-snmp-community-strings.txt $ip
```
Brute against a list of hosts
```bash
onesixtyone -c /usr/share/wordlists/SecLists/Discovery/SNMP/snmp.txt -i targets.txt
```

## 2. Authenticated Enumeration

"Auth" = knowing the community string. Once you do, dump everything.
Full dump to a file
```bash
snmpwalk -v 2c -c public $ip > snmp.txt
```
Grep the dump for sensitive keywords
```bash
cat snmp.txt | grep -iE 'user|pass|admin|route|process'
```
Walk system OID (name, uptime)
```bash
snmpwalk -v 2c -c public $ip 1.3.6.1.2.1.1
```
Walk Windows users OID
```bash
snmpwalk -v 2c -c public $ip 1.3.6.1.4.1.77.1.2.25
```
Walk running processes OID
```bash
snmpwalk -v 2c -c public $ip 1.3.6.1.2.1.25.4.2.1.2
```
Walk installed software OID
```bash
snmpwalk -v 2c -c public $ip 1.3.6.1.2.1.25.6.3.1.2
```
Walk interfaces OID
```bash
snmpwalk -v 2c -c public $ip 1.3.6.1.2.1.2.2.1.2
```
Walk routes OID
```bash
snmpwalk -v 2c -c public $ip 1.3.6.1.2.1.4.21.1
```

## 3. Password Spraying / Bruteforcing

Community string brute = the answer here, not passwords.
Brute community strings with onesixtyone
```bash
onesixtyone -c /usr/share/wordlists/SecLists/Discovery/SNMP/common-snmp-community-strings.txt $ip
```
Brute community strings with nmap
```bash
nmap -sU -p 161 --script snmp-brute $ip
```
Brute community strings with nxc
```bash
nxc snmp $ip -c /usr/share/wordlists/SecLists/Discovery/SNMP/common-snmp-community-strings.txt
```
Brute community strings with hydra
```bash
hydra -P /usr/share/wordlists/SecLists/Discovery/SNMP/common-snmp-community-strings.txt $ip snmp
```

## 5. Quick Wins

### 5.1 Default string works → full dump
```bash
snmpwalk -v 2c -c public $ip > snmp.txt
grep -iE 'pass|user|admin|secret' snmp.txt
```

### 5.2 Windows target → enumerate users/software via SNMP
```bash
snmpwalk -v 2c -c public $ip 1.3.6.1.4.1.77.1.2.25   # user list
```

### 5.3 Read-only string still leaks a lot — never discount it
```bash
# Read-only (public) still dumps processes, users, software, interfaces.
```

## 6. Config Paths

snmpd (Linux)
```text
/etc/snmp/snmpd.conf
```
Windows SNMP service
```text
HKLM\SYSTEM\CurrentControlSet\Services\SNMP\Parameters
```

Config quick-reference:
```text
snmpd.conf -> rocommunity public, rwcommunity private, access control
```

## 7. Post-Exploit / Pivot

- Dumped users → spray across SMB/SSH/WinRM/HTTP
- Dumped processes/software → identify vuln software for exploit selection
- rwcommunity (write) → can set values (sometimes used to write routes/config)

### Common gotchas
```text
- UDP-based → use -sU on nmap, and note UDP scans are slow.
- Only v2c/v1 typically. v3 needs auth/priv creds (rare on OSCP).
- Public (read-only) is enough to win — write community (private) is a bonus, not required.
- onesixtyone is much faster than snmpwalk for brute — use it first.
- onesixtyone -c <file> $ip works, but for many hosts use -i targets.txt.
```
