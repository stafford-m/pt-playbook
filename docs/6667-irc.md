# 6667 - IRC

## Service Usage

Connect with nc
```bash
nc -nv $ip 6667
```
Connect with irssi (IRC client)
```bash
irssi -c $ip -p 6667
```

## 0. Fast Path (try these first)

Grab banner and MOTD
```bash
timeout 5 nc $ip 6667
```

## 1. Banner Grab & Unauthenticated Enumeration

Version and default-script scan
```bash
nmap -p 6667 -sV -sC $ip
```
Manual connection (leaks version, MOTD, channels)
```bash
nc -nv $ip 6667
```
Set NICK during manual session
```bash
NICK test
```
Set USER during manual session
```bash
USER test 0 * :test
```
List channels during manual session
```bash
LIST
```

## 2. Authenticated Enumeration

Most IRC doesn't need auth, but some servers have NickServ/Oper auth.
Manual connection
```bash
nc -nv $ip 6667
```
Set NICK during manual session
```bash
NICK test
```
Set USER during manual session
```bash
USER test 0 * :test
```
(List/who/topic commands for intel)
```bash
# /list, /who, /topic for intel
```

## 6. Config Paths

UnrealIRCd
```text

```

```text

```

## 7. Post-Exploit / Pivot

- Known IRCd backdoor → immediate shell (UnrealIRCd)
- MOTD/channel intel → creds or hostnames

### Common gotchas
```text
- UnrealIRCd 3.2.8.1 backdoor = the single most likely IRC vuln on OSCP. Check version first.
- IRC is almost never the intended path — treat as a quick check, then move on.
```
