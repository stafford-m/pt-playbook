# 5900/5800 - VNC

## Service Usage

Connect
```bash
vncviewer $ip:$port
vncviewer $ip:1          # display 1 = port 5901
```

## 0. Fast Path (try these first)

Check auth + version:
```bash
nmap -p 5900-5905 -sV -sC $ip
```
Default/blank passwords are the main win on VNC.

## 7. Post-Exploit / Pivot

- GUI → terminal → full compromise
- Saved browser/credential data → reuse

### Common gotchas
```text
- Display N = port 5900+N. Display :0 = 5900, :1 = 5901.
- 5800 is HTTP (web VNC) on some old setups.
- VNC auth may not log failures — brute carefully.
```
