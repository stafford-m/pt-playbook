# 445/139 - SMB

## Service Usage

Basic auth check
```bash
smbclient -L $ip -N                        # null/anonymous session - list shares
smbclient -L $ip -U $un%$pw               # authenticated - list shares
```
Connect to a share
```bash
smbclient //$ip/$share -U $un%$pw
smbclient //$ip/$share -N                  # null session
```
Standard Commands (inside smbclient)
```bash
ls
cd $dir
get $file           # download single file
mget *              # download all in dir (toggle prompt off with 'prompt')
put $file           # upload single file
mput *              # multiple upload
recurse ON          # enable recursive for mget/mput
prompt OFF          # disable per-file confirmation
```
Mount a share (as root)
```bash
mount -t cifs //$ip/$share /mnt/smb -o username=$un,password=$pw
```

## 0. Fast Path (try these first)

Credential reuse: if you have creds from another service (FTP, HTTP, LDAP, etc.), try them on SMB before reaching for brute force.

Null session / guest check — never skip this:
```bash
smbclient -L $ip -N
rpcclient -U "" -N $ip      # blank user, no pass
```

Enumerate without creds — quick win sweep:
```bash
enum4linux -a $ip           # does most of the below in one shot
```
Note: enum4linux can be slow/noisy — fall back to the manual rpcclient/nmap commands in §1 if it hangs.

## 1. Banner Grab & Unauthenticated Enumeration

Version / OS detection
```bash
nmap -p 139,445 -sV -sC $ip
```

SMB-specific NSE scripts (enumeration only — safe for OSCP)
```bash
nmap -p 445 --script smb-enum-shares,smb-enum-users,smb-enum-domains $ip
nmap -p 445 --script smb-security-mode,smb-os-discovery $ip
nmap -p 445 --script smb-protocols $ip         # SMB version — critical for exploit selection
```

Null session users/shares via rpcclient
```bash
rpcclient -U "" -N $ip -c "srvinfo; enumdomusers; enumalsgroups domain; lsaquery"
```

netexec (manual commands, not exploits)
```bash
netexec smb $ip -u '' -p '' --shares
netexec smb $ip -u '' -p '' --users
netexec smb $ip -u 'guest' -p '' --shares
```

## 2. Authenticated Enumeration

netexec — enumerate everything once you have creds
```bash
netexec smb $ip -u $un -p $pw --shares
netexec smb $ip -u $un -p $pw --users
netexec smb $ip -u $un -p $pw --groups
netexec smb $ip -u $un -p $pw --sessions
netexec smb $ip -u $un -p $pw --local-groups
netexec smb $ip -u $un -p $pw --loggedon-users
```

rpcclient — query the box
```bash
rpcclient -U "$un%$pw" $ip -c "enumdomusers"
rpcclient -U "$un%$pw" $ip -c "enumdomgroups"
rpcclient -U "$un%$pw" $ip -c "queryuser 500"      # RID 500 = built-in admin
rpcclient -U "$un%$pw" $ip -c "netshareenumall"
rpcclient -U "$un%$pw" $ip -c "querydispinfo"
```

List all shares (incl. hidden `$` shares) and recursively pull a share
```bash
smbclient -L $ip -U $un%$pw
smbmap -H $ip -u $un -p $pw -R          # recursive listing of all readable shares
```

Pull files with smbclient (recursive, no per-file prompt)
```bash
smbclient //$ip/$share -U $un%$pw -c "recurse ON; prompt OFF; mget *"
```

**ALWAYS enumerate `$` shares (ADMIN$, C$, IPC$) — writable ADMIN$ or C$ is often the intended path.** Hidden/non-default shares and dotfiles are the highest-yield targets.

## 3. Password Spraying / Bruteforcing

*Last resort — try null session + known/guest creds first; brute force is usually a time sink.*

Spray one password across users
```bash
netexec smb $ip -u users.txt -p 'Spring2026!' --continue-on-success
```

Brute force with hydra
```bash
hydra -L users.txt -P pass.txt smb://$ip
```

Spray a known-valid local admin password across hosts (movement)
```bash
netexec smb targets.txt -u Administrator -p 'Passw0rd!' -d . --continue-on-success
```

## 5. Quick Wins

### 5.1 Check for known SMB vulns (enumerate only — verify manually before exploiting)
```bash
nmap -p 445 --script smb-vuln-ms17-010 $ip
nmap -p 445 --script smb-vuln-ms08-067 $ip
```

### 5.2 Writable share → upload a payload, but recall you still need a way to trigger it
```bash
netexec smb $ip -u $un -p $pw --shares     # find a writable share / writable ADMIN$ C$
# If a share is served (web/scripts dir), upload and trigger via HTTP — see HTTP notes
```

### 5.3 SMB2/SMB3 remote exec WITHOUT attacking tools — if you have admin creds:
```bash
# psexec via impacket (manual, allowed — not metasploit)
impacket-psexec $domain/$un:$pw@$ip
impacket-wmiexec $domain/$un:$pw@$ip
impacket-smbexec $domain/$un:$pw@$ip
```

### 5.4 Check for unconstrained delegation / anonymous DCOM (rare but exam-relevant):
```bash
netexec smb $ip -u $un -p $pw --shares
```

## 6. Config Paths

Samba
```text
/etc/samba/smb.conf
/usr/local/samba/lib/smb.conf
```
Windows Registry (share perms / audit)
```text
HKLM\SYSTEM\CurrentControlSet\Services\LanmanServer\Shares
```

Config quick-reference:
```text
smb.conf     -> check for: writable = yes, guest ok = yes, valid users, restrict anonymous
Windows      -> check ADMIN$ / C$ write rights (that's the win, not the config file)
```

## 7. Post-Exploit / Pivot

- Writable share → web shell/upload → HTTP notes
- Admin creds + WinRM open (5985) → impacket-wmiexec / evil-winrm → see WinRM notes
- lsass / SAM dump for lateral movement → see Windows PrivEsc notes
- SMB relay (only if SMB signing = disabled) → see NTLM relay notes

### Common gotchas
```text
- 445 closed but 139 open? Try SMB1 via -p 139 / add 'client max protocol = SMB2' to smb.conf if modern target refuses SMB1.
- "NT_STATUS_LOGON_FAILURE" on a correct-looking pw? Try WORKGROUP vs domain, or add -d . for local auth.
- SMB signing disabled/required: 'nmap --script smb2-security-mode' reveals it — relay attacks need signing disabled.
- Kerberos vs NTLM: if clock skew / "KRB_AP_ERR_SKEW", check target timezone/drift.
```

### Command map (moved psexec/wmiexec here for context)
```text
impacket-psexec  -> interactive SYSTEM shell (needs admin, port 445)
impacket-wmiexec -> shell over WMI (port 135/5985, quieter than psexec)
impacket-smbexec -> semi-interactive, uses SMB only
netexec          -> enumeration + creds + --exec-method smbexec/atexec for command exec
```
